# API REST de autenticación

Proyecto de una API REST para gestionar usuarios.

Incluye:

- Registro de usuarios.
- Verificación de correo electrónico.
- Inicio de sesión con contraseña y token JWT.
- Almacenamiento de usuarios en MongoDB.
- Envío de correos con Nodemailer.
- Pruebas de la API con Postman.

Desarrollado con Node.js, Express, Mongoose y MongoDB.
